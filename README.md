# Nexus

Nexus is an Unreal Engine 5 project focused on C++ gameplay programming, the Gameplay Ability System (GAS), and multiplayer functionality.

The project serves as a learning project and a portfolio piece to demonstrate gameplay systems implemented with a combination of C++ and Unreal Engine Blueprints.

## Features

- Gameplay Ability System: Abilities, attribute sets, gameplay effects, and gameplay cues.

- Combat mechanics: Melee attacks, sword combos, dash, projectile attacks, and area-of-effect abilities.

- Character systems: Player and enemy character classes with shared gameplay functionality.

- Multiplayer: Client-server connection setup and multiplayer gameplay experiments.

- Inventory system: Item definitions, world pickups, and an inventory UI.

- Interactive gameplay: A vending machine ability that uses GAS to manage gameplay interactions.

## Project Structure

- Source/Nexus/GameplayAbilitySystem/ — C++ gameplay abilities, attribute sets, characters, and supporting systems.

- Source/Nexus/InventorySystems/ — Inventory-related C++ classes and item definitions.

- Content/GameplayAbilitySystem/ — GAS-related Blueprint assets.

- Content/InventorySystem/ — Inventory Blueprints and UI assets.

- Config/ — Unreal Engine project configuration.

The project is under development. Features and systems are being implemented and refined as part of ongoing game programming studies.
